## 解题链路

每套样题的 Python 解题链路固定 5 个脚本，`代码/` 与 `样题完整记录/` 各存一份（按赛季与样题分目录）：

| 脚本 | 作用 |
|---|---|
| `数据清洗.py` | 按题目步骤逐步清洗，每步输出 `cleaned_*.csv` |
| `数据标注.py` | 分类标注，输出 `*_mark.csv` / `*_level.csv` |
| `数据分析.py` | 数据分析若干问，结果格式化打印到终端 |
| `数据可视化.py` | matplotlib / pyecharts 出图，pyecharts 输出 HTML |
| `业务分析.py` | 业务指标计算与运营建议输出 |

## 快速开始

脚本用相对路径读写 CSV，需以样题目录为工作目录运行（`代码/` 与 `样题完整记录/` 均可直接跑，以 2024-2025 样题1 为例）：

```bash
cd 代码/2024-2025/样题1
python -X utf8 数据清洗.py    # 先清洗，产出中间 CSV
python -X utf8 数据标注.py    # 再标注，依赖清洗产物
python -X utf8 数据分析.py
python -X utf8 数据可视化.py
python -X utf8 业务分析.py
```

Windows 控制台建议加 `-X utf8` 避免 GBK 乱码；无显示器环境运行可视化脚本可加 `MPLBACKEND=Agg`。

安装依赖：

```bash
pip install pandas numpy matplotlib pyecharts
```

## SQL 脚本

`SQL/code/` 按赛季与样题划分脚本：建库、建表、建用户、查询。MySQL 运维配置（安装、导入数据、最大连接数、慢查询日志、binlog、远程连接、字符集、备份与定时备份等）的命令见对应 markdown 笔记。`SQL/数据/` 提供配套建表数据 CSV，`LOAD DATA` 入库后即可直接执行查询脚本。
