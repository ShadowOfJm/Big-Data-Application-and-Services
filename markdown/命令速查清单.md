#### 5. 数据库备份与恢复
```
# 使用mysqldump备份数据库
mysqldump -u root -p bigdata > bigdata_backup.sql

# 恢复数据库
mysql -u root -p bigdata < bigdata_backup.sql

# 创建定时备份脚本(每天凌晨2点)
cat > /opt/backup.sh << 'EOF'
user="root"
pass="password"
date=$(date +%Y%m%d_%H%M%S)  
database="数据库名"   # 备份的数据库
backup="/opt/backup" # 备份的路径
mysqldump -u"$user" -p"$pass" "$database" > "${backup}/${database}_backup_$date.sql"
find "$backup" -name "${database}_backup_*.sql" -mtime +7 -delete
EOF
chmod +x /opt/backup.sh
(crontab -l 2>/dev/null; echo "0 2 * * * /opt/backup.sh") | crontab -
```

## 二、模块二：数据处理与标注
### (一) Pandas数据处理命令
```
import pandas as pd
import numpy as np

# 读取CSV文件
df = pd.read_csv('data.csv')

# 查看数据基本信息
print(df.head())  # 查看前5行
print(df.info())  # 查看数据结构
print(df.describe())  # 查看统计信息

# 数据清洗
df = df.drop_duplicates()  # 删除重复行
df = df.dropna()  # 删除缺失值
df['column'] = df['column'].fillna(value)  # 填充缺失值

# 数据转换
df['new_column'] = df['column'].apply(lambda x: transform_func(x))  # 应用函数转换

# 条件筛选
df_filtered = df[df['price'] > 500]  # 筛选价格大于500的记录
df_filtered = df[(df['area'] > 50) & (df['price'] < 500)]  # 多条件筛选

# 分组统计
grouped = df.groupby('district')
avg_price = grouped['price'].mean()  # 按区域计算平均价格
count_by_type = grouped['layout'].count()  # 按区域统计户型数量

# 聚合操作
result = df.groupby('district').agg({
    'price': 'mean',
    'area': 'mean',
    'house_id': 'count'
}).rename(columns={
    'price': 'avg_price',
    'area': 'avg_area',
    'house_id': 'total_count'
})

# 排序
sorted_df = df.sort_values(by='price', ascending=False)  # 按价格降序排序

# 新增列(数据标注示例)
# 根据学习时长标注学习模式
def label_learning_pattern(row):
    if row['avg_duration'] > 60 and '21:00' <= row['peak_time'] <= '23:00':
        return '夜间学习型'
    elif row['avg_duration'] > 60 and '09:00' <= row['peak_time'] <= '12:00':
        return '上午学习型'
    else:
        return '普通学习型'

df['learning_mode'] = df.apply(label_learning_pattern, axis=1)

# 保存处理结果
df.to_csv('learning_pattern.csv', index=False)
```

### (二) SQL数据处理命令
```
-- 创建表(示例：房源信息表)
CREATE TABLE house_info (
  house_id INT PRIMARY KEY,
  community VARCHAR(100) NOT NULL,
  district VARCHAR(50) NOT NULL,
  layout VARCHAR(50) NOT NULL,
  area DECIMAL(10,2) NOT NULL,
  price DECIMAL(12,2) NOT NULL,
  floor_info VARCHAR(50),
  orientation VARCHAR(50),
  status ENUM('在售', '已售', '下架') DEFAULT '在售'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 创建表(示例：小区信息表)
CREATE TABLE community_info (
  community_id INT PRIMARY KEY,
  community_name VARCHAR(100) NOT NULL,
  district VARCHAR(50) NOT NULL,
  total_houses INT,
  avg_price DECIMAL(12,2)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 插入数据
INSERT INTO house_info VALUES (1, '育慧里一区', '朝阳', '2室1厅', 52, 343, '5/6', '南', '在售');

-- 基本查询
SELECT * FROM house_info;
SELECT community, district, price FROM house_info;

-- 条件查询
SELECT * FROM house_info WHERE price < 500;
SELECT * FROM house_info WHERE district = '朝阳' AND area > 50;

-- 聚合查询
SELECT district, AVG(price) AS avg_price FROM house_info GROUP BY district;
SELECT layout, COUNT(*) AS total FROM house_info GROUP BY layout;

-- 多条件聚合
SELECT district, layout, AVG(price) AS avg_price, AVG(area) AS avg_area, COUNT(*) AS total 
FROM house_info 
GROUP BY district, layout;

-- 排序查询
SELECT * FROM house_info ORDER BY price DESC;
SELECT district, AVG(price) FROM house_info GROUP BY district ORDER BY AVG(price) DESC;

-- 复杂条件查询(样题中的典型查询)
-- 筛选出卫生评分和服务评分均高于4.5的酒店
SELECT * FROM hotel WHERE hygiene_score > 4.5 AND service_score > 4.5;

-- 筛出售价在平均售价以下且面积超过平均面积的房源
SELECT * FROM house_info 
WHERE price < (SELECT AVG(price) FROM house_info) 
AND area > (SELECT AVG(area) FROM house_info);

-- 统计每种房间类型的出现频次，进行正序排序展示前两名
SELECT room_type, COUNT(*) AS frequency 
FROM hotel 
GROUP BY room_type 
ORDER BY frequency ASC 
LIMIT 2;
```

## 三、实用小技巧
1. **HDFS命令速记**：
    - 创建目录：`hadoop fs -mkdir 目录路径`
    - 上传文件：`hadoop fs -put 本地文件 HDFS路径`
    - 下载文件：`hadoop fs -get HDFS路径 本地路径`
    - 查看文件：`hadoop fs -cat HDFS文件路径 | head -n 行数`
2. **MySQL权限管理口诀**：
    - 创建用户：`CREATE USER '用户名'@'%' IDENTIFIED BY '密码';`
    - 授予权限：`GRANT 权限 ON 数据库.表 TO '用户名'@'%';`
    - 刷新权限：`FLUSH PRIVILEGES;`
3. **Pandas数据处理流程**：
    - 读取数据 → 数据清洗 → 数据转换 → 数据分析 → 保存结果
    - 常用方法链：`df.dropna().groupby('列').mean().reset_index()`
4. **SQL查询结构**：
    - SELECT 列名
    - FROM 表名
    - WHERE 条件
    - GROUP BY 分组列
    - HAVING 分组后条件
    - ORDER BY 排序列
    - LIMIT 限制行数
