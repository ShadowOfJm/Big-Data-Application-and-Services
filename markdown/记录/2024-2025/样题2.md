### 3.子任务三：数据表的创建及维护
(1)`use education;` 使用education库(若需要)
创建course表
```mysql
create table course (
	id int primary key ,
	course_name varchar(n),
	category varchar(n),
	level varchar(n),
	duration int ,
	price decimal(n,n),
	instructor varchar(n),
	avg_rating float,
	enrollment_count int
) ;
```
(2)创建learning_record表
```mysql
create table learning_record (
	id int primary key,
	user_id int,
	course_id int,
	watch_duration int,
	completion_rate float,
	last_watch_time datetime,
	quiz_score float,
	study_duration int
) ;
```
(3)查询每门课程的平均完成率
```mysql
select
	l.course_id,
	avg(l.completion_rate) as 平均完成率
from
	learning_record as l
group by
	l.course_id;
```
统计每个课程类别的总报名人数
```mysql
select
	category,
	sum(enrollment_count)
from
	course
group by
	category;
```
查找观看时长超过课程时长的学习记录
```mysql
select
	l.course_id,
	l.watch_duration,
	l.completion_rate,
	l.last_watch_time,
	l.quiz_score,
	l.study_duration
from
	learning_record as l
join
	course as c
on
	l.course_id = c.id
where
	l.watch_duration > c.duration;
```
