	spot_id int,
	visit_date date,

	peak_hour time,
	weather varchar(n),
	is_holiday boolean,

(3)查询2024年1月每个景区的总游客人数。查询结果需要显示景区名称、所在城市和游客总数，并按游客总数降序排列
```mysql
select
	s.spot_name,
	s.city,
	sum(v.visitor_count) as 游客总数
from
	visitor_flow as v
join
	scenic_spot as s
on
	v.spot_id = s.spot_id
where
	year(v.visit_date) = 2024 and month(v.visit_date) = 1
group by
	s.spot_id,
	s.spot_name,
	s.city
order by
	游客总数 desc;
```
统计**每个景区**在**节假日**和**非节假日**的平均游客数量。查询结果需要显示**景区名称、景区等级、节假日平均游客数和非节假日平均游客数**，按景区编号排序
```mysql
select
	s.spot_name,
	s.level,
	avg(case when v.is_holiday = true then v.visitor_count end) as 节假日平均游客数,
	avg(case when v.is_holiday = false then v.visitor_count end) as 非节假日平均游客数
from
	scenic_spot as s
join
	visitor_flow as v
on
	s.spot_id = v.spot_id
group by
	s.spot_id,
	s.spot_name,
	s.level
order by
	s.spot_id;
```
找出**所有景区**中单日游客量超过该景区最大承载量的情况。查询结果需要显示景区名称、参观日期、实际游客数量、最大承载量和超出人数， 按超出人数降序排列
```mysql
select
	s.spot_name,
	v.visit_date,
	v.visitor_count,
	s.max_capacity,
	(v.visitor_count - s.max_capacity) as 超出人数
from
	scenic_spot as s
join
	visitor_flow as v
on
	s.spot_id = v.spot_id
where
	v.visitor_count > s.max_capacity
order by
	超出人数 desc;
```

## (二)任务二：业务分析
### 1.基础指标分析
(1)客流指标分析：全年共接待游客 2746 人次，覆盖 366 天，日均客流量 7.50 人次/天；客流波动系数（标准差/平均值）为 0.3808，波动幅度偏大；节假日客流比因数据中没有节假日标记字段无法直接计算，改用周末与工作日的日均客流之比 7.14 / 7.65 = 0.93 作为近似参考。分景区看日均游客量，丽江古城与桂林山水最高 1.49 人次/天，黄山最低 1.38 人次/天，各景区客流分布相当均衡
(2)消费行为分析：人均消费 610.60 元（总消费 1676706.00 元 / 2746 人），平均停留 5.85 小时。按年龄段分组，55+ 组 628.82 元最高、46-55 组 589.18 元最低；按来源地分组，青岛 695.35 元、大连 694.72 元、厦门 667.37 元位居前三
(3)游客体验评估：满意度评分为 5 分制，2746 条记录全部在有效范围内（0.0～5.0），加权平均值 2.54 分，得分率 50.88%，游客体验整体偏低；分景区看长城最高 2.66 分、故宫最低 2.40 分

### 2.运营建议
(1)差异化票价策略：客流波动系数 0.3808 说明各日客流起伏明显，建议按淡旺季与工作日/周末分档定价——周末与工作日客流基本持平（7.14 vs 7.65 人次）说明提价空间有限，但对春节、五一、十一等法定节假日应实施分时段动态上浮，工作日推出淡季折扣门票以平衡峰谷
(2)服务优化方案：满意度加权平均仅 2.54 分（得分率 50.88%），且满意度与停留时长几乎不相关（r = 0.0063），说明现有的服务体验与游客停留行为脱节，应从排队时长、导览讲解、卫生与设施维护等具体环节入手整改，而不是指望延长停留时间带动满意度，并建立月度满意度回访机制
(3)精准营销建议：高价值游客占 12.06%，55+ 组消费最高（628.82 元），自驾出行消费能力最强（644.51 元），据此对 55+ 客群与自驾人群设计深度游、康养主题与房车营地组合产品；针对占比 76.37% 的低价值游客推出文创、餐饮与二次讲解等增值服务，把人均消费从 610.60 元提升到景区平均消费水平以上
