统计各省份的平均酒店评分,并将评分低于该省份平均分的酒店评分上调0. 5分(评分上限为5分)
```mysql
update hotel as h
set h.score = least(h.score + 0.5,5)
where h.score < (
	select
		avg(h2.score) as 平均分
	from
		hotel h2
	where
		h.province = h2.province
);
```
查找出每个城市评论数最多的酒店及其详细信息
```mysql
select
	h.*
from
	hotel h
where
	cast(h.commnet_num as int) = (
	select
		max(h2.commnet_num)
	from
		hotel as h2
	where
		h.city = h2.city
	);
```
找出所有发表过3条及以上差评（评分小于等于2分）的评论人，并列出这些评论人的**评论时间、评论内容及对应的酒店名称**，按评论时间降序排序
```mysql
select
	c.commentator,
	c.comment_time,
	c.content,
	c.name
from
	comment as c
where c.commentator in (
	select
		commentator
	from
		comment
	where
		score <=2
	group by
		commentator
	having
		count(*) >= 3
)
order by
	c.comment_time desc;
```
