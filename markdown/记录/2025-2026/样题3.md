## (一)任务一：AI 大模型服务综合部署
### 1.子任务一：基本配置
本任务需要使用 root 用户完成相关配置，已提供操作系统镜像及需要配置的前置环境，所需软件安装包均在 /root/ 目录下
(1)`mkdir -p /media/cdrom` 在 AI-SRV 中将操作系统镜像挂载至 /media/cdrom，并实现开机自启
情况一：**镜像文件在 `/root/` 目录下**
```
mount -o loop /root/openEuler-22.03-LTS-SP4-x86_64-dvd.iso /media/cdrom
```
情况二：**镜像已通过虚拟光驱加载到设备 `/dev/sr0`**
```
mount /dev/sr0 /media/cdrom
```
编辑 `vim /etc/fstab`
```
末尾添加
/dev/sr0    /media/cdrom    iso9660    defaults,ro    0    0
```
**注意**：
    `/dev/sr0` 光驱设备名（用 `lsblk` 确认）
    `/media/cdrom` 挂载点
    `iso9660` 光盘文件系统类型
    `defaults,ro` 表示默认选项且只读（推荐加 `ro` 以避免警告）
    `0 0` 表示不备份、不检查
`mount -a` 验证
如果没有报错，说明配置成功
(2)`vim /etc/yum.repos.d/local.repo` 在 AI-SRV 中完成软件源配置文件的编写，禁用 GPG 校验，并为源数据建立缓存
```
[local]
name=Local Repository
baseurl=file:///media/cdrom
enabled=1
```
