配置节点时
若是动态ip则 `vim /etc/sysconfig/network-scripts/ifcfg-ens33` 配置静态ip
```
BOOTPROTO="static"          //修改：将dhcp修改为static，修改后为BOOTPROTO=static
ONBOOT=yes                  //修改为yes, 网卡开机自启动
IPADDR="xxx.xxx.xxx.xxx"    //新增：配置静态IP地址，按需配置
NETMASK="255.xxx.xxx.xxx"   //新增：配置子网掩码
GATEWAY="xxx.xxx.xxx.xxx"   //新增：配置网关
DNS1="xxx.xxx.xxx.xxx"      //新增：配置DNS
```
`systemctl restart network` 重启服务

在安装完mysql之后执行 `mysql -u root -p` 会让你输入密码
临时密码在 `/var/log/mysqld.log`
登录完立即修改密码
`alter user 'root'@'%' identified by '密码';`
如果密码太简单会报错执行以下指令来设置降低密码校验，复杂程度为简单，长度为4
`set global validate_password.policy = 0;`
`set global validate_password.length = 4;`
